Rules
  • Crest: primary fill, secondary emblem, theme outline 2.5/64. Never recolour a crest per theme; swap the outline only.
  • Emblem vs primary ≥ 3.7:1 for every club.
  • Standalone marks use the theme values (all ≥ 3:1). Secondaries are supporting marks; never the only identifier.
Avoided on purpose
  • Claret + sky blue, black + white stripes, yellow + green, amber + black, yellow + navy, green + white, red + white.
  • Lions, cannons, liver birds, roses, stars above crests, lettering, crossed tools.
