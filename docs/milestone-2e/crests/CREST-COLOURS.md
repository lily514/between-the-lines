## Colour-blind separation

Smallest CIELAB ΔE between any two club primaries (Machado 2009 simulation, full severity):

| Set | Typical | Deutan | Protan | Tritan |
|---|---|---|---|---|
| Crest | 20.9 | 11.9 | 13.4 | 10.5 |
| Dark theme | 25.9 | 11.0 | 11.4 | 10.9 |
| Light theme | 20.9 | 11.6 | 13.4 | 10.5 |

Colour is never the only identifier: the emblem and the club name or code always appear with it.

## Rules

- Never recolour a crest per theme; swap the outline only (or use the matching file).
- Minimum size 24 px. Don't place text inside or over a crest.
- Secondaries are supporting marks; use the primary (or the crest) when a club needs one colour.
- Avoided: claret + sky blue, black + white stripes, yellow + green, amber + black, yellow + navy, green + white, red + white; lions, cannons, liver birds, roses, stars above crests, lettering, crossed tools.

## Drawing rules (revision 2)

- Emblems stay inside r 25.5 of the centre, clear of the outline (inner edge r 28.25).
- No emblem feature thinner than 3 units; each emblem must still read at 24 px.
- Filled silhouettes in the secondary colour; small cut-outs (eyes, windows) in the primary.
- Subjects drawn in profile or front-on so they can't be mistaken for one another: front-on badger only; birds and the otter in profile or hover.
- Revision 2 redrew BAK, TRU, WEL, SHE and WHI, replaced ALN's woven grid with a weaver's shuttle (the grid read as "#"), and evened stroke weight and scale on RIP, HEX, PEN and LUD. Colours are unchanged, so every ratio above still holds.

## Before launch

Every town used has a real local club. Check each name, nickname and crest against that club, and consider invented town names if anything clashes.
